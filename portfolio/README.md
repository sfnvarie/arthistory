# Portfolio pratico

Selezione delle produzioni nate dal percorso di studio.

Non è un archivio di ogni prova: conserva soprattutto gli esercizi riusciti o quelli utili per capire un passaggio della ricerca personale.

Per ogni lavoro annotare, quando utile:

- mese/capitolo di riferimento;
- problema storico-artistico affrontato;
- medium utilizzato;
- breve nota critica sul risultato.

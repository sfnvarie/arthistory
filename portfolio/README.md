# Portfolio pratico

Il portfolio raccoglie una selezione delle produzioni nate dal percorso, non ogni prova eseguita.

Per ogni lavoro selezionato conservare quando utile:
- mese/capitolo di riferimento;
- problema storico-artistico affrontato;
- medium utilizzato;
- link al file o alla documentazione;
- breve nota critica: scelta formale, risultato, cosa cambiare;
- eventuale feedback ricevuto e revisione successiva.

Gli elaborati personali non devono essere caricati automaticamente nella repo pubblica. Nel sito operativo i link e le note vengono salvati in Firestore sotto l'account autenticato. File pesanti possono restare su storage esterno e venire collegati.

Alla fine di ogni mese selezionare almeno i lavori più significativi, non necessariamente i più 'riusciti': può essere utile conservare anche una prova che chiarisce un problema della ricerca.

Per la struttura tecnica e didattica completa leggere `../programma/STRUTTURA_STANDARD.md`.

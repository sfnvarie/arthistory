# Verifiche

Qui vanno le verifiche di fine mese e le sintesi dei passaggi stratificati.

Ogni verifica mensile dovrebbe includere:

- riconoscimento e collocazione delle opere-cardine;
- sintesi orale o scritta delle trasformazioni principali;
- breve verifica critica su una o due letture;
- revisione del portfolio pratico;
- nota finale: cosa è rimasto poco chiaro e cosa merita approfondimento nel giro successivo.
